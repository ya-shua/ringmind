记忆容量

每一圈最多装多少条。装满了会挤掉旧的那条。

⚠ 容量和时间是两道闸门，谁先到算谁。装满了会挤掉旧的，时间到了会掉下去。时间在「记忆时间」里调。
系统推荐
三套是固定模板，只能选、不能改。想按自己的来，就「新建一个自己的方案」——建的时候拿当前这套做底稿，之后随便改。

记忆时间

每一圈待多久。待满就掉到下一圈，回忆圈待满就彻底忘掉。

⚠ 时间是硬闸门：到点就往下掉，不管装没装满。
系统推荐
系统只给一套「默认方案」，只能看不能改。想按自己的来，就点「新建自己的方案」——拿当前这套做底稿，之后随便改。

记忆模式

决定忘不忘、忘多少、能不能被提醒起来。

✓
遗忘模式
会忘。被提醒能想起来一部分，但永远想不全。最像人。
✓
伪遗忘模式
看起来忘了，一提示全回来。自己也以为忘了。
✓
永不忘记模式
总库开放，什么都能查回来。适合当档案型角色。
✓
自定义
每一圈单独调比例，想怎么配怎么配。
