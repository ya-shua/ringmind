# 接声来 · 让她开口说话

> 环心记得住她说过什么，声来让她**怎么说的**。
> 这层适配和 astrbot 转发插件一个思路：环心本体一行不改，声来也不用改，中间只靠一个 HTTP 接口。

---

## 链路

```
她的文字回复 ──► 声来 /api/speak（选好的音色 + 文字）──► 音频文件
     │                                              ──► AstrBot Record 组件
     └─ 文字照常发 ──────────────────────────────► QQ 语音跟一条
```

---

## 前置

1. **声来面板**在跑：双击桌面「声来」（或 ZCode 里 `/voice:panel`），确认 <http://127.0.0.1:17878> 能开
2. 声来里登记好至少一个音色（免费音色大厅挑一个，或用「造声音」做一个）

---

## 三步装好

### 1. 接入模型（如果还没接）

声来面板「⚙️ 模型接入」→ 选模型 → 填 Key → 保存。
（小米 MiMo 限时免费，已有 Key 的话 9 个免费音色随便用；百炼/硅基同便宜）

### 2. 装 AstrBot 插件

把本目录整个丢进 AstrBot 的插件目录：

```
<AstrBot>/data/plugins/astrbot_plugin_shenglai_voice/
```

在 AstrBot WebUI 的插件页启用它。

### 3. 对话验证

发一条消息 → 她的文字回复下面会跟一条 QQ 语音。
`/voice_off` 临时关掉，`/voice_on` 再开。

---

## 配置

环境变量（改 AstrBot 启动环境或插件内顶部常量）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `SHENGLAI_URL` | `http://127.0.0.1:17878` | 声来面板地址 |
| `SHENGLAI_VOICE` | 测试御姐 | 用哪个登记过的音色 |
| `SHENGLAI_RATE` | 1.0 | 语速 |
| `SHENGLAI_TIMEOUT` | 30 | 合成超时（秒） |

---

## 说明

- **只做搬运**：文字 → 音频的转换全部由声来完成，本插件只负责调接口和挂 Record 组件
- **合成失败不丢回复**：语音挂了文字照发
- **免费额度**：Edge/MiMo 免费；百炼几厘钱一句；具体见声来「指南」页
- **长回复不合成**：超过 500 字自动跳过（防刷屏防超时），可以用 `/voice_off` 彻底关
