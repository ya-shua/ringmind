# 声来语音 · 通用客户端

把「一句话 → 一条语音」这件事抽成一份谁都能用的东西。**不认框架，只认声来的 HTTP 接口。**

```
你的机器人 ──文本──► tts.speak() ──GET /api/speak──► 声来面板 ──► wav 文件 ──► 你的机器人发出去
```

**声来本体不是这个仓库里的东西**：它是一个独立面板（默认 `127.0.0.1:17878`），
跟记忆库、跟任何机器人框架都没关系，谁都能调它的 `/api/speak`。

这里放的只是**调用方**：从「某个框架的插件」里剥出来的那一小块，方便各家复用。

## 为什么还要这一份

`integrations/astrbot/` 那份里只有 4 行跟语音有关，其余全是 AstrBot 的 import、
`result.chain`、`Comp.Record`。海螺要用就得把那 4 行再抄一遍 ——
抄一遍就再踩一遍同样的坑（超时、把错误 JSON 当音频、临时文件不删）。

所以抽出这一份：任何语言、任何框架都能用。

## 三种用法

**1. Python 直接 import**

```python
from tts import speak
wav = speak("今天中午吃的面不错")
if wav:
    send_record(conv_id, wav)   # 你框架的发语音接口
    os.unlink(wav)
```

**2. 命令行（任何语言都能 exec）**

```bash
python tts.py -t "今天中午吃的面不错" -o reply.wav
python tts.py -t "你好" -o a.wav --voice 测试御姐 --rate 1.1
python tts.py --check          # 只看声来面板通不通
```

**3. 只要协议，自己实现**（Node、Go、Rust 都行）

```
GET http://127.0.0.1:17878/api/speak?voice=<音色>&rate=<语速>&text=<URL 编码的文本>
→ 200 + WAV 二进制；失败返回 JSON（所以小于 512 字节一律当失败）
```

## 三条约定（踩过的）

1. **失败绝不抛异常**：返回 `None` / 退出码 1。语音挂了不能拖垮文字回复 —— 文字照发。
2. **长度上限 500 字**：再长就别合成，又慢又贵，而且没人听完。
3. **一次一个临时文件**，调用方删。别在磁盘上攒垃圾。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `SHENGLAI_URL` | `http://127.0.0.1:17878` | 声来面板地址 |
| `SHENGLAI_VOICE` | `测试御姐` | 默认音色（声来面板里登记的名字） |
| `SHENGLAI_RATE` | `1.0` | 语速 |
| `SHENGLAI_TIMEOUT` | `30` | 超时（秒） |

## 和记忆库的关系

**没有关系。** 语音合成不往记忆库写任何东西 —— 记忆库只记「谁说了什么」，
不记「这句话是怎么发声的」。之前有插件一次合成写一条工具回执进闲聊圈，
一夜灌了 54 条，那个做法已经禁掉了。
