# 海螺（conch）· 在用

> 海螺是独立项目（`插件/海螺`），这边只记「怎么接记忆库」，不放它的代码。

海螺跑在 DSH 里，所以它走 **MCP**，不走 HTTP —— 同一个进程里的工具，不用开端口。

## 接入点

一个函数就够：`plugins/conch/main.py` 的 `remember_into_ring()` / `remember_own()`，
内部调记忆库的 `ring_ingest`。

## 四个问题怎么答的

| 问题 | 海螺的做法 |
| --- | --- |
| 哪段对话 | `_conv_key()`：群 `group:<群号>`；私聊有称呼卡 `private:card:<卡名>`（一卡多号算同一个人），没卡 `private:<QQ号>` |
| 谁说的 | 别人的话 `speaker="user"`；她自己发出去的话 `speaker="self"`（在发送成功之后才写，没发成功不算她说过） |
| 消息 id | 收到的消息用框架的 `message_id`；她自己的话用 `out:<turn_id>` |
| 语音 | 转写进正文并带 `[语音转写]` 标记，`note` 写「语音转写，可能不准」 |

## 踩过的两个坑（写在这里省得再踩）

1. **一开始不传 `conv_key`**，只传 `source`。记忆库只能按 `private` / `group` 分组，
   于是**所有私聊共用一个合并槽** —— 张三和李四的私聊会被拼成同一条。
   判据①「同一个聊天」就这么被绕过去了。
2. **`speaker` 传显示名**。记忆库的衰减按 `speaker` 分两条路，只有 `self` 才有 ×3 存活；
   传显示名等于全员普通待遇。
